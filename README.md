# afifo — FPGA 异步 FIFO 指针跨域检查模块

离散事件的异步 FIFO 指针/旗标硬件模型，用于离线数字硬件验证。仅用 Python
标准库从零实现，核心算法不依赖、不调用任何第三方 FIFO 实现。

## 环境与依赖

- Python **3.14.7**（Linux 原生验证；不使用 3.14 之外的语法特性时亦可在
  较早的 3.x 上运行，但以 3.14.7 为准）。
- **无第三方依赖**，无需安装任何包；离线运行，不访问网络、硬件、数据库或
  云服务。

## 准确命令

```bash
python -m unittest discover -s tests -v   # 必要测试（55 个用例）
python demo.py                            # 固定输入演示，实时计算
```

`demo.py` 为固定字面值调度（无随机、无 `sleep`、无预录输出），在本机实测
远小于 8 秒（约 0.03 秒），打印正常工作轨迹、指针回绕轨迹、**读写域独立
复位与世代双向确认轨迹（满队列复位、再次复位）**，以及真实触发的硬件拒绝
与契约异常。

## 包结构与公开接口

```
afifo/
  __init__.py
  gray.py     # binary_to_gray / gray_to_binary
  model.py    # AsyncFIFO, Event, EdgeRecord, AsyncFIFOError
tests/
  reference_model.py  # 独立参考（不 import afifo）+ 抽象队列核对
  test_afifo.py

```

### `AsyncFIFO(k)`

- `k`：深度对数，**仅接受整数 1..5**（`bool` 拒绝），深度 = 2^k（2..32），
  读写指针均为 **k+1 位**（k 位地址 + 1 位回绕位）。
- `run_one(event) -> EdgeRecord`：施加一个时间步并返回完整硬件轨迹。
- `run(iterable_of_events) -> list[EdgeRecord]`：原子批次。整个批次先全部
  校验再施加，任何一步非法则批次完全不生效（无部分变更）；接受生成器；
  单批上限 **100 000** 个事件。
- `reset()`：回到**上电态**（世代也归零）并清空轨迹。流内单域复位请用
  `Event(wrst=True)` / `Event(rrst=True)`，它们不清空轨迹。
- 属性：`k`、`depth`、`wptr`、`rptr`、`full`、`empty`、`steps`、
  `accepted_writes`、`accepted_reads`、
  `wgen`/`rgen`（当前世代号，上电为 0，每次本域复位脉冲 +1）、
  `wready`/`rready`（本域世代已与对端二级同步值一致）、
  `synchronized`（双方都 ready，传输门打开）、`snapshot()`。

### `Event(time, wclk, rclk, wen=False, ren=False, wdata=None, wrst=False, rrst=False)`

- `time`：整数时间戳，`0 <= time < 2^63`；同一 FIFO 内必须**严格递增**。
- `wclk`/`rclk`：必须为 `bool`，且每步至少一个为 `True`（双停非法）。
- `wen`/`ren`：必须为 `bool`。
- `wdata`：`wen=False` 时必须为 `None`；浮点载荷必须有限（NaN、+/-Inf
  一律拒绝）。其他类型载荷原样存入按地址寻址的存储器。
- `wrst`/`rrst`（新增，必须为 `bool`，默认 `False`）：本域复位脉冲，
  **必须伴随本域时钟沿**（`wrst=True` 要求 `wclk=True`，`rrst=True` 要求
  `rclk=True`）。旧代码以 6 个以内位置参数构造 `Event` 的调用全部继续
  可用。

### `EdgeRecord`（每步轨迹，字段即文档）

`time, wclk, rclk, wen, ren, w_accept, r_accept, wptr_before/after,
rptr_before/after, wgray_before/after, rgray_before/after,
full_before/after, empty_before/after, r2w_before/after,
w2r_before/after, wdata, rdata, wrst, rrst,
wgen_before/after, rgen_before/after,
rgen2w_before/after, wgen2r_before/after,
wready_before/after, rready_before/after`。

- `w_accept`/`r_accept` 为 `None` 表示该域本步未时钟；`True/False` 表示
  接受/拒绝。
- `r2w`/`w2r` 为 `(一级同步, 二级同步)` 的**指针**格雷元组；
  `rgen2w`/`wgen2r` 为对应的**世代**格雷元组；`before` 是边沿采样的
  旧寄存器值。

### 错误语义

- 所有契约错误抛 `afifo.AsyncFIFOError`（`ValueError` 子类），消息包含
  参数名；批次错误包含 `events[i]` 索引，可定位，不静默纠正。
- 数值输入拒绝 NaN/Infinity（见上）；所有整数形参拒绝 `bool`。
- 核心没有搜索/求解过程，因此**不存在“搜索预算耗尽”这一结果类别**；
  非法输入直接报错，语义上不与任何“无解”混淆。

## 硬件语义（实现的契约）

1. 只有格雷码跨时钟域：**指针格雷**驱动旗标，**世代格雷**驱动复位握手；
   每域各有两套两级同步器。**读写同刻边沿时双方都采样旧状态**，包括
   同步器输入级锁存的对端旧格雷（`s1<=旧对端格雷，s2<=旧s1`）——但若
   该刻有显式复位脉冲，则**先执行复位、再采样**，对端这一拍锁存到的是
   复位后的零值。
2. `full` 是写域寄存器，复位 `False`；`empty` 是读域寄存器，复位 `True`。
3. 当前边沿先用**旧旗标**决定是否接受：写接受当且仅当
   `wclk and wen and not full_old and 传输门打开`，读接受当且仅当
   `rclk and ren and not empty_old and 传输门打开`。无复位时传输门恒开。
4. 旗标随后按“接受后的本地下一指针格雷”与“**旧**二级同步输出”更新：
   - `empty_next = (gray(rptr_next) == w2r_s2_old)`（仅 rclk 沿刷新）
   - `full_next  = (gray(wptr_next) == (r2w_s2_old ^ 0b11<<(k-1)))`
     （最高两位取反比较；仅 wclk 沿刷新）
   - **本域世代尚未被对端确认（`wready/rready` 为假）时，旗标保持复位
     值**（empty=True / full=False），不用旧世代残留的对端指针对算，
     避免响应式复位前后指针链与世代链短暂错拍造成的空读。
5. 停钟（`wclk/rclk=False`）冻结该域全部寄存器（指针、旗标、两套同步器）。
6. 旗标**只由指针格雷与同步寄存器推出**，从不读取存储器或任何全局队列
   长度；存储器按 k 位地址读写，仅用于数据面与读出核对。因此旗标天然
   保守：跨域两级延迟期间可能出现“非满报满 / 非空报空”，造成合法请求被
   拒绝——`demo.py` 的 t=8..15、t=21..22 与 t=2..4 明确展示该延迟。

### 独立域复位与世代双向确认协议

- `wrst`/`rrst` 是随本域时钟沿给出的复位脉冲。每收到一个脉冲：本域
  指针归零、本域旗标回复位值、本域内全部同步寄存器（指针两级 + 世代
  两级）清零、**存储器清空**、接受读写计数归零、本域世代号 +1。
- 新世代号格雷经对端**既有的两级同步器**跨域：对端第二级解出的世代号
  **严格大于**本端世代号时，对端执行同样的复位动作并采用该世代号（响应
  式复位），再把该世代号经自己的两级同步器回声回去。只有世代号更新才
  被采用，旧世代的迟到/回声值永不回滚世代，因此**对端响应前连发第二个
  复位脉冲**也只会收敛到最新世代，握手窗口里的任何旧确认都无法误开门。
- 从复位脉冲当刻起，直到双方第二级世代寄存器都等于同一世代号
  （`synchronized=True`），**两域所有使能一律拒绝**——即使复位域本侧
  看不到对端时钟、或对端还没察觉到复位（最多两个本域时钟沿的窗口）。
  典型收敛拍数（交替单边时钟）：发起后第 2 个对端沿响应，再第 2 个
  本域沿回声完成；同刻双沿两边各自独立走两级。
- 世代号为无界 Python 整数（相邻世代格雷仍只差一位），本模型不模拟
  世代计数器位宽回绕与亚稳态窗口。

## 输入上限汇总

| 项目 | 上限 / 范围 |
|---|---|
| k | 整数 1..5（深度 2..32，指针 2..6 位） |
| time | 0 .. 2^63-1，严格递增 |
| 单批事件数 | 100 000 |
| 载荷 | 任意 Python 对象；浮点必须有限；`wen=False` 时必须为 `None` |
| wrst/rrst | 必须 `bool`；为 `True` 时本域时钟沿必须同时有效 |
| 世代号 | 无界非负整数（每次本域复位 +1），不模拟位宽回绕 |

这些是接口边界；短演示不穷举上限规模。

## 验证方法

- **手工锚点**：`tests/test_afifo.py` 含手工推导的格雷表（0..15）、一张
  k=1 的完整复位→填满→保守拒绝→排空寄存器波形表（逐字段比对），以及
  k=2 的填满→写域复位→世代握手→恢复传输逐拍波形表（含世代格雷在两级
  同步器中的位置与响应式复位拍点）。
- **独立参考差分**：`tests/reference_model.py` 不导入 `afifo`，独立重述
  格雷公式、全部时序与世代复位握手；对 k=1..5、9 种时钟频比（含同刻）、
  停钟窗口、长程回绕（k=1 与 k=5），以及单/双边复位、对端响应前连发
  复位、复位期间对端停钟、同刻双复位逐寄存器差分。
- **抽象队列核对**：另用 `collections.deque` 仅核对“已接受数据”的 FIFO
  顺序与占用恒在 `[0, 深度]`（防越界），任何复位同时清空该抽象队列；
  它不参与被测旗标逻辑。
- 格雷 `gray_to_binary(binary_to_gray(v)) == v` 仅作补充往返检查。

## 浮点与误差口径

核心只做**整数位运算**（指针、格雷、旗标），不存在浮点计算结果，因此
**没有数值误差、不使用任何容限**。浮点只可能作为不透明载荷出现，仅做
有限性校验后原样存取，不参与任何比较或算术。

## 设计取舍

- 事件时间用整数轴（不模拟物理亚稳态与具体相位）：同一时刻可给出
  wclk/rclk 双沿，语义统一定义为“双方采样旧寄存器”，确定可复现。
- 格雷跨域只建模“合法但可能滞后一到两拍”的值，不建模亚稳态采样窗口。
- 数据面用按地址索引的列表，纯粹为演示读出数据顺序；旗标逻辑结构上不
  接触它（有测试扫描源码保证）。
- `Event` 使用带校验的普通不可变值类（`__slots__`），因为 Python 3.14
  禁止覆盖 `typing.NamedTuple.__new__`；仍支持属性访问、相等比较与解包。

## 已知限制 / 非目标

- 只实现本题契约的**有限子集**：k=1..5、离散整数时间、单一二进制反射
  格雷与两级同步；**不宣称兼容任何行业标准总线/FIFO 规范**，不建模
  亚稳态概率、复位释放同步器的物理时序、时序约束或真实 FPGA 原语。
- 复位协议在模型层保证“确认前不传、复位清旧数据、同刻先复位后采样”，
  世代号无界增长；**不建模世代计数器位宽回绕**，也不建模异步复位释放
  亚稳态（复位始终被当作随沿生效的同步脉冲）。
- 不做几乎满/几乎空（almost-full/empty）、分组计数、数据校验（ECC/
  parity）、多写多读端口。
- 不提供网站、通用 CLI、看板或持久化；终端命令仅用于测试与演示。
